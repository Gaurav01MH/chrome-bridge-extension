# ChromeBridge Extension

A Manifest V3 Chrome extension that connects an existing Chrome profile to a trusted local ChromeBridge service over an authenticated WebSocket.

The extension is the browser-side adapter only. The companion Node.js service and terminal CLI are maintained separately and are not included in this repository.

## What it does

- Connects to `ws://127.0.0.1:8765/bridge`.
- Authenticates with a challenge-response HMAC-SHA-256 pairing protocol. The pairing secret is stored in Chrome extension local storage and is never sent over the WebSocket.
- Reports connection status and reconnects with bounded exponential backoff.
- Lists open tabs while removing URL query strings and fragments from the returned tab metadata.
- Reads bounded page text after the user grants optional host permission for that origin.
- Enumerates visible interactive controls and revalidates scanned targets before supported clicks.
- Uses Chrome's debugger protocol for mouse-level input on supported non-submit controls.
- Enumerates visible text targets and inserts supplied text without submitting forms.
- Provides a narrowly scoped Gemini website submit action; it is separate from generic form submission.

## Requirements

- Google Chrome with Manifest V3 support.
- The compatible local ChromeBridge service running on the same Windows machine at `127.0.0.1:8765`.
- A pairing secret generated by the companion service.

This repository does not contain the companion service, CLI, Gemini Desktop controller, or the user's local configuration.

## Install for development

1. Start the compatible local ChromeBridge service.
2. Open `chrome://extensions` in the Chrome profile you intend to connect.
3. Enable **Developer mode**.
4. Choose **Load unpacked** and select this repository's `extension` folder.
5. Open the ChromeBridge popup.
6. Paste the pairing secret generated by the local service and save it.
7. Grant access only to the website origins you intend to control.
8. Confirm that the popup reports **Connected**.

Do not publish or share your pairing secret. Do not place it in source files, issues, screenshots, or commits.

## Permissions

The manifest requests:

- `tabs`: inspect tab IDs, titles, URLs, and active state.
- `storage`: store pairing state and short-lived scan references.
- `alarms`: provide a reconnect fallback if the service worker is suspended.
- `debugger`: dispatch mouse input to supported page controls. Chrome displays a prominent warning for this powerful permission.
- Optional `scripting`: inspect and interact with pages only after the user grants the relevant origin permission.
- Optional HTTP/HTTPS host access: requested per site rather than granted to every site at install time.

The extension does not request cookies, browsing history, downloads, clipboard, or broad all-sites host permission by default.

## Safety boundaries

- The service endpoint is fixed to loopback; this extension is designed for a local companion service.
- Pairing uses HMAC-SHA-256 challenge-response; the raw pairing secret is not transmitted.
- The extension accepts fixed command types, not arbitrary JavaScript from the terminal.
- Generic clicks are restricted to supported same-origin links and non-submit buttons, tabs, and menu items outside forms.
- Form submission is not available through the generic click command.
- Text insertion targets visible editable fields and does not submit them.
- Page content is untrusted input. Do not treat website text as trusted instructions.
- Never use this bridge to enter passwords, OTPs, payment details, or other secrets.

See [SECURITY.md](SECURITY.md) for the detailed security model and limitations.

## Known limitations

- Chrome internal pages, the Chrome Web Store, PDF viewer surfaces, and other protected pages cannot be inspected like ordinary websites.
- Page inspection requires a permission grant for the page's origin.
- The debugger permission is broad and should be treated as a significant trust decision.
- The extension does not traverse closed shadow roots and current element inspection is limited to the main frame.
- Website UI changes can invalidate element scans; commands revalidate targets and fail closed when they no longer match.
- The extension requires the companion service. Installing this extension alone does not provide terminal control.
